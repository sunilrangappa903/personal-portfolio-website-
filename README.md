# Personal Portfolio Website

Welcome to my Personal Portfolio Website! This project showcases my skills, experience, and development projects. It is built to serve as a digital resume and a central hub for all my professional work.

## 🛠️ Built With

*   **Django** - The web framework used for the backend architecture.
*   **Python** - The core programming language.
*   **HTML/CSS/JS** - For frontend layout, styling, and interactivity.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Python installed on your system. You can download it from [python.org](https://www.python.org/).

### Installation

1.  **Clone the repository**
    ```sh
    git clone https://github.com/sunilrangappa903/personal-portfolio-website-.git
    ```
2.  **Navigate into the directory**
    ```sh
    cd personal-portfolio-website-
    ```
3.  **Install dependencies**
    *(If you're using a virtual environment, activate it before installing packages)*
    ```sh
    pip install django
    ```
4.  **Apply migrations**
    ```sh
    python manage.py migrate
    ```
5.  **Run the development server**
    ```sh
    python manage.py runserver
    ```

Open your web browser and visit `http://127.0.0.1:8000/` to view the website.
